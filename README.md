# AI Research Agent

## Project Overview

This project implements an AI-powered research agent that retrieves real-time information from the web and generates structured research summaries. The agent combines DuckDuckGo Search for information retrieval with Anthropic Claude for summarization and analysis.

The project was implemented in Google Colab using Python and demonstrates the integration of web search with large language models for automated research assistance.

---

## Objectives

- Retrieve real-time information from the web
- Summarize information from multiple sources
- Generate structured research reports
- Integrate DuckDuckGo Search with Anthropic Claude
- Demonstrate automated information retrieval and summarization

## Project Workflow

### 1. Environment Setup

- Installed the required libraries
- Configured the Anthropic API
- Initialized the language model

### 2. Information Retrieval

- Accepted a research topic
- Retrieved relevant web search results using DuckDuckGo
- Collected search summaries

### 3. Prompt Construction

Combined the following information before generating a response:

- Research topic
- Web search results
- System instructions

### 4. Research Generation

- Generated a structured research summary using Claude
- Produced concise findings based on retrieved information
